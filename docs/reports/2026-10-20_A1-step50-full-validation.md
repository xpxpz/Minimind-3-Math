训练配置为 rank=16、alpha=16、dropout=0，注入 8 层 Q/O 共 16 个投影层、393,216 个参数；此前共处理 800 条训练题。基础模型为 63,912,192 参数的 MiniMind-3，权重 SHA256 为 `3adf69402b5d22e693151cabadc12528f923c4ba6bf343738aaf13f0892162e8`。

这次在完整 **1,000 道 validation 题**上生成，不再使用 24 题限制；其中基础计算 334、混合运算 333、应用题 333。正式 ID/OOD 测试集不用于本轮生成或调参。代码基于提交 `170d095`，工作区有未提交改动；运行清单保留实际代码/环境与数据身份。

| 基础计算 | 334 | 67 | 20.06% |
| 混合运算 | 333 | 1 | 0.30% |
| 应用题 | 333 | 73 | 21.92% |
| 单步加法 | 154 | 0 | 0% |
| 单步减法 | 159 | 0 | 0% |
| 单步乘法 | 161 | 0 | 0% |
| 单步除法 | 193 | 140 | 72.54% |
| 不含任何除法的表达式 | 691 | 0 | 0% |

类型子集之间部分交叉，不能将表中所有行相加。不含除法子集包括单步加减乘与不含除法的混合算式；单步除法不包括 `(a-b)/c`。

有效且未截断的答案为 988/1,000；另有解析失败 11 题、截断 1 题、运行错误 0 题。其余 847 题为格式可判分但数值错误。

141 个正确答案中，140 个是将单步除法的两个整数操作数保留为分子/分母；唯一正确的混合运算为 `(24 - 28) / 25`，标准答案和输出均为 `-4/25`。这至少包含一次正确的减法结果，但单个样本不能支持稳定的多步计算结论。

## 6. 结论、限制与完成项

完整验证显示，当前 14.1% 的成绩几乎全部集中于可以直接写成分数的单步除法；不含除法的 691 题均未答对。现阶段格式学习较明显，普通算术学习仍不足。

已完成：50 步权重快照、1,000 题生成、运算分类/输出行为诊断、7 项新增测试、原始输出和元数据归档。证据见 [结果目录](../../results/evidence/2026-10-20-A1-step50-full)、[运行清单](../../results/evidence/2026-10-20-A1-step50-full/run.json)、[逐题输出](../../results/evidence/2026-10-20-A1-step50-full/predictions.jsonl)、[分析结果](../../results/evidence/2026-10-20-A1-step50-full/analysis.json)。

本轮没有对原始未微调模型生成完整 1,000 题，因此不能把此前的 0/24 当作同分母的完整 Baseline。这里只诊断同一 50 步模型；下一阶段将与更大训练预算的模型在相同 1,000 题上比较。结果用于验证集诊断，不是正式测试或无偏泛化结论。
